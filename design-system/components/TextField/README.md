# TextField

Labelled text input for learning and account flows.

**Consumer provides:** `label` (always visible — never rely on the placeholder), optional `help` or `error`, and any `<input>` props.

48px tall, `radius-default`, `surface-container-highest` border, `on-surface-variant` text. Focus: `primary` border + `powder-blue` ring. Error: `error` border and message.
