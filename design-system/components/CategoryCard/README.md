# CategoryCard

Icon-first card for the professional-skill category grid (AI, Digital Accounting, Digital Marketing, Cybersecurity, Web Design, Graphic Design).

**Consumer provides:** `title` (English category label is fine), `icon` (a 40px line icon), optional `count`, `href` or `onClick`, `active`.

- White `surface`, `radius-default`, `shadow-card`, padding 35px 30px 25px; about 300 × 197px.
- Hover or `active` fills with `primary` and turns the text `on-primary`.
- Lay out in a 3/2/1-column grid with a `space-gutter` gap.
