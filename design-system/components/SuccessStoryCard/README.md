# SuccessStoryCard

Documentary proof: a grayscale learner photo, an outcome-led sentence, name, role and a link to the story or video.

**Consumer provides:** `image` (a real learner photo; it is rendered grayscale), `outcome`, `name`, `role`, `href`, `video` (shows a play mark).

Keep it quieter than the enrolment CTA; no star ratings or badges here.
