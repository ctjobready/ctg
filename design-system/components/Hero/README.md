# Hero

The career hero: a luminous radial sky gradient with copy on the left and a learner portrait on the right.

**Consumer provides:** `eyebrow`, `title`, `lead` (one paragraph), `actionLabel` + `href`/`onAction`, up to three real `stats`, and `image` (a learner portrait).

- Background: radial `hero-gradient-center` → `hero-gradient-edge`; never a flat saturated blue.
- Headline `display-5xl` (32/40 on mobile); content inside `content-max`; top padding 70px desktop, 40px mobile.
- Order: eyebrow → headline → paragraph → primary CTA with arrow → stats.
- Stacks to one column below `bp-tablet`. The preview shows a placeholder where the portrait goes.
