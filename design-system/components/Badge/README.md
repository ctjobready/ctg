# Badge

Pill-shaped labels, 22px tall, for discounts, status and the hero eyebrow.

**Consumer provides:** `children` (a few words) and `tone`.

- `sale` — `sale-badge-bg` with a 1px `sale-badge-border`; the course discount marker.
- `brand` — Airy Blue label for delivery mode or category.
- `info` / `success` — informational and completed states; always include the word, not just colour.
- `eyebrow` — the small label above a hero headline.

Don't: stack more than two badges on one card.
