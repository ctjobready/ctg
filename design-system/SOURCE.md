# Design system source

These files are a read-only copy of the owner's Claude Design System **"JobReady Global"** (tokens.json, brand-book README, component guidelines and reference stylesheet), copied 2026-10-08.

- `tokens.json` is the source of truth for `src/styles/tokens.css` (generated by `scripts/build-tokens.mjs`, Accessible (AA) theme).
- `components/bundle.css` and `components/*/README.md` are the reference for the Astro component ports in `src/components/system/`.
- Do not edit these files by hand; update them from the design system and regenerate tokens.
