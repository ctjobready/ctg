## Your Role and Responsibilities

We are seeking a talented WordPress Frontend Web Developer who specializes in crafting engaging and visually stunning user experiences within the WordPress ecosystem and Shopify.

The following list of key responsibility areas (KRAs) and responsibilities you will take on is indicative, not exhaustive. You’ll have a reasonable workload that can assure high-quality results.

### WordPress/Shopify Customization and Content Management

- Customize WordPress themes to match the desired design aesthetics and functionality
- Design and develop visually appealing and user-friendly frontend interfaces for Shopify ecommerce websites using HTML, CSS, JavaScript and Shopify Liquid language
- Develop and customize WordPress front-end design and templates using Elementor page builder ensuring responsiveness and visual appeal
- Customize and extend WordPress/ Shopify themes to meet project requirements, ensuring consistency with brand guidelines and design specifications
- Design and configure e-commerce WordPress websites using WooCommerce
- Implement responsive and mobile-first design principles to ensure optimal viewing experiences across various devices and screen sizes

### Integration, Optimization and Troubleshooting

- Integrate and configure WooCommerce and Shopify apps to enhance website functionality, including payment gateways, shipping solutions, product reviews and marketing tools
- Implement backend functionalities using PHP to enhance the functionality and interactivity of websites
- Integrate third-party plugins and APIs to extend the capabilities of WordPress websites
- Optimize website performance, security and database management using best practices
- Contribute to the team’s knowledge base by documenting processes, guidelines and lessons learned
- Conduct thorough testing and debugging to identify and resolve frontend issues, ensuring cross-browser compatibility and adherence to best practices

### Responsive Websites with User Interface Design

- Implement frontend designs using HTML, CSS and JavaScript, with a focus on React/Svelte/Astro framework
- Conduct research on current design trends, best practices and emerging technologies to contribute to innovative design solutions
- Maintain and update existing websites, ensuring consistent design standards and branding guidelines
- Optimize website designs for performance, accessibility and user experience across various devices and browsers
- Create wireframes, prototypes and mockups using design software and tools
- Develop visually appealing website layouts, incorporating graphics, images and other visual elements

## Qualifications and Skills

### Mandatory

To qualify to enter the selection process for this job, you must meet the following minimum criteria. Please DO NOT apply if you do not meet these criteria:

- Bachelor’s in computer science, software engineering or a related field.
- Proficiency in HTML, CSS and JavaScript, with a strong emphasis on frontend development.
- Strong knowledge of React or any similar mature framework, and PHP
- Experience with WordPress theme development, customization with page builder tools specifically Elementor and plugin integration.
- Good knowledge and experience in Shopify frontend customization.
- Proficient in design software such as Adobe Photoshop, Illustrator, Figma or Sketch.
- Good understanding of user interface (UI) principles and best practices.

### Preferred

If you have the following skills/competence, you’ll have a competitive advantage in our selection process compared to others:

- Good understanding of user experience (UX) principles, Design Systems and best practices.
- Understanding of SEO principles and website optimization techniques.
